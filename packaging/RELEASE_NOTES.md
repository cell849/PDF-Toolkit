# 0.8.9

- Add optional Start menu and Desktop shortcuts from the File menu.
- Existing shortcuts are preserved; the app remains portable.

**[Download PDFToolkit.zip for Windows](https://github.com/cell849/PDF-Toolkit/releases/download/v0.8.9/PDFToolkit.zip)**

Extract the complete folder and open **PDFToolkit.exe**. Keep `_internal` beside it.
GitHub's Source code links below the download contain the corresponding project source.

The EXE is self-signed. This checks integrity but does not establish a trusted
publisher, so Windows SmartScreen warnings can remain. The hosted build uses a
temporary certificate; its public certificate and verification instructions are
included, but its private key is not distributed. Optional conversion engines
are installed separately. The app runs offline.
