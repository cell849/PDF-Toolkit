# Version 0.8.6

- Larger, rounded navigation chevrons and blue selection and focus outlines.
- The Windows archive and executable use the shorter PDFToolkit filename.
- License texts and dependency notices are included with the Windows download.

Download **PDFToolkit.zip** under Assets, extract the complete
folder and open **PDFToolkit.exe**. Keep `_internal` beside it. The separate
**PDFToolkit-source.zip** contains the corresponding project source; a SHA-256
checksum accompanies the app ZIP.

The EXE is self-signed. This checks integrity but does not establish a trusted
publisher, so Windows SmartScreen warnings can remain. The hosted build uses a
temporary certificate; its public certificate and verification instructions are
included, but its private key is not distributed. Optional conversion engines
are installed separately. The app runs offline.
